# Licensing Boundary

OPP uses separate licenses for implementation artifacts and the protocol
specification.

| Surface | License |
| --- | --- |
| `spec/` protocol specification | CC BY 4.0 |
| `schemas/` and OpenAPI definitions | Apache-2.0 |
| `conformance/` | Apache-2.0 |
| `sdk/` | Apache-2.0 |
| `providers/` | Apache-2.0 |
| `simulators/` | Apache-2.0 |
| `sandboxes/simulation/` | Apache-2.0 |
| Reference implementations or server code | Apache-2.0 |
| Other repository content unless separately marked | Apache-2.0 |

The top-level `LICENSE` contains Apache License 2.0. The `spec/` exception is
declared in `spec/LICENSE.md` and applies recursively to specification content
unless a file states otherwise. Third-party material and dependencies retain
their own licenses and must be identified when introduced.

## Compatibility and Marks

Copyright licenses permit implementation and adaptation subject to their terms;
they do not establish OPP compatibility or certification. This repository does
not currently operate an “OPP Certified” program or grant a compatibility mark.
A future trademark and compatibility policy must define the mark, conformance
requirements, authorized claims, and governance separately.

## Commercial Services

The open-source licenses do not require future hosted or managed services to be
open source. Any such service is outside this repository unless explicitly
contributed here under the applicable repository license.
