## Source Access

Official AI-resource discovery begins at the [AI resources page][ai], which
publishes separate [documentation][docs-index] and [API reference][ref-index]
indexes. Individual documentation pages are available as Markdown by adding
`.md` to their URL.

The first slice uses Checkout Transparente via Orders API, the currently
recommended integration. Payments API is explicitly indexed as legacy and is
not treated as the same contract. Evidence is documentation-only; no API call
has been made.
