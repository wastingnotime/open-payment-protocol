# Provider Research

Research providers independently before comparing them. The initial set is
Asaas, Iugu, Mercado Pago, PagBank, and Pagar.me.

Each provider directory should contain `contract.md`, `lifecycle.md`,
`errors.md`, `webhooks.md`, sanitized `fixtures/`, and optional sanitized
`recordings/`. Use `template.md` as the starting point.

`comparison.md` may summarize only claims supported by provider research.
